# The Door Counts

A compact, original Godot 4.6.3 horror microgame. Open five seals before the doors count you. Each round shuffles four named sigils, asks for one, and rerolls whether the instruction is truthful or lying. A lie requires the named sigil's opposite. This is a small truthful/opposite ruleset, not arbitrary generated puzzles.

## Play the Web build

1. Extract the Web ZIP into a folder.
2. Open a terminal in that folder and run `python -m http.server 8000 --bind 127.0.0.1` (on Windows, `py -m http.server 8000 --bind 127.0.0.1` also works).
3. Open http://127.0.0.1:8000 in a modern desktop browser. Keep the terminal open while playing. Stop with Ctrl+C.

Do not double-click index.html: browser security prevents a Godot Web export from loading via file://. This build does not require cross-origin isolation headers. Python must already be installed for the example server.

## Controls and rules

Enter begins/retries. 1–4 or a mouse click chooses a door. R replays the same seed, N starts the next seed, Space/Escape pauses. The bottom buttons provide the same actions. First seal allows 14 seconds; later seals allow 13, 12, 11 and 10. Pause freezes both timers and rule transitions. Wrong choices and timeout end the run; inputs cannot advance after losing or winning.

Truth: choose the named sigil. Lie: choose its opposite. Bell ↔ Moon; Eye ↔ Tooth. Read the printed sigil names and rule words: color is not required. Symbols may move after each seal. Five correct choices wins. The brief horror ending is fictional; the game has no network requests, accounts, saves or real-world file tricks.

## Editable source

Import `project.godot` into Godot 4.6.3. Play with F6/F5 or run:

```
godot --path .
godot --headless --path . -- --test
```

Export presets are included for Web, Linux x86_64 and Windows x64. Matching official Godot templates are required. Windows is an unsigned cross-export, not a native-runtime-tested release. Keep its EXE and PCK together.

## Linux build

Extract the Linux ZIP, run `chmod +x the-door-counts.x86_64` if needed, then `./the-door-counts.x86_64`. The exact exported executable passed its embedded headless gameplay test using `./the-door-counts.x86_64 --headless -- --test` from outside the source project. A graphical Linux playthrough remains unverified.

## Verification

Automated Godot tests pass legal paths for seed 104729 (keys 1,4,4,1,3) and 104730 (3,2,4,2,4), showing different required first actions and full sequences. Tests cover wrong choices, deterministic restart, timeout, pause, reroll, same named sigil under both rules, and 100 seeded legal paths. Independent headless QA checked all-five reproducibility and terminal/transition input guards.

Web export passed with official 4.6.3 templates. Its exact exported PCK also passed the gameplay test when loaded by the native Godot engine from an isolated directory; this validates packaged content, not WebAssembly/browser runtime. Browser runtime and visual QA were blocked in the build environment by its local-socket restriction; the build must not be described as browser-playtested. No screenshots are represented as actual runtime captures. See TEST_REPORT.md for scope.
